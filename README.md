# Scratch Binary 3 Compiler
Compiles a subset of Javascript into scratch's sb3 file format

> [!CAUTION]
> This project is unfinished and under active development, expected lots of bugs, changes, and missing functionality.

## Building
Run: `go build`

## Running
Build and run: `./sb3c`, or skip building and run directly with: `go run .`

## Installing
Run: `go build && sudo cp sb3c /usr/bin`
